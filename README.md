# SumoSearch

Sumo Search is a python utility to search the logs from Sumo search. It uses the Sumo Search API to search the logs and return the results in a readable format.
Search results can be piped or saved for further processing.
The whole idea to create this utility is to have a developer utility/tool, which can be invoked by Claude/Copilot to debug the issues based on the logs from SumoLogic.
